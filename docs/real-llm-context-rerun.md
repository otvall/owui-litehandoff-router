# Повторная real-LLM приёмка после исправления

2026-11-10, официальный OWUI 0.13.3 в изолированном контейнере,
реальная бесплатная `nvidia/nemotron-3.5-lightning:free`, синтетические данные.
Использованы исправленные исходники, standalone exports и промпты стенда.

## Результат

Полная приёмка не пройдена: модель снова выдала два delegate_task разными
генерациями. Первая группа создала одного работника; вторая отклонена.
Валидатор завершился `AssertionError: An additional assignment was rejected`.

Защита после исправления подтверждена: финального lite_delegate не было,
Router показал один фактический прогноз и прямо сообщил, что второй не выполнен.
Дублирования единственного ID в качестве двух результатов больше нет.
Первый работник выполнил один worker_lookup. Стоимость всех успешных
генераций прогона по usage — 0.

## Доступность маршрутов

- Nemotron с parallel_tool_calls=true и require_parameters=true: 404,
  endpoint не принимает запрошенный набор параметров; генераций нет.
- Inkling 2 Small free: 403, модель недоступна в регионе; генераций нет.
- Nemotron без неподдерживаемого optional параметра: реальный прогон завершён.
  Условия проверки двух фактических одновременных calls сохранены.

На момент проверки публичный каталог бесплатных Tool-capable моделей
не заявлял parallel_tool_calls. Это не доказывает невозможность нескольких
calls по умолчанию; runner позволяет явно включить optional параметр через
LHR_OPENROUTER_PARALLEL=1 и выбрать другую бесплатную модель через
LHR_OPENROUTER_MODEL. Платные модели runner запрещает.

Сценарии отсутствия наблюдений, отдельного handoff, A+B и терминала не
выполнялись: приёмка остановлена на первом проваленном критерии.
Задачи 3.3 и 5.4 остаются открытыми.

[Входы и результаты](real-llm-context-rerun.json) сохранены отдельно от исходного
failed trace. Ключ в отчёт и конфигурацию OWUI не включался; временные файлы
ключа удалены на host и внутри контейнера (trap при любом исходе).
