# Single-agent Tool calls: проверка

Публичный `delegate_task(agent_id, task, file_ids?)` запускает ровно одного
работника. Четыре назначения выдаются четырьмя Tool calls одной генерации.
Параллельность и привязку outputs к call IDs обеспечивает native loop OWUI.
Пакетный `lite_parallel` больше не публикуется.

Проверено 2026-11-10 на официальном OWUI 0.13.3 в изолированном контейнере
`lhr-0133-checks-20261109`. LLM scripted, HTTP/native loop, Tools, Skills,
MCP, файлы и дочерние чаты — настоящие. Локальная `.venv` содержит 0.12.3,
поэтому она использовалась только для unit suite; native результаты взяты
из целевого контейнера.

- Unit: 90/90.
- Native: 65/65, без skips; standalone exports и четыре отдельных calls.
- HTTP: два пользователя, четыре пересекающихся исполнения, отдельные
  outputs, правильный порядок, реальные Tool/MCP chains, закрытые файлы
  и чаты, полный пакет для handoff и свежий Router follow-up.
- Перекрытие всех четырёх worker Tool-интервалов: 0.940 и 0.957 секунды.
- HTTP lifecycle: Stop, общий timeout, удаление родителя и cleanup children.
- HTTP controls: отключение лимитом 0, handoff A/B, общий ответ Router,
  частичный отказ обязательного ресурса без handoff, явная ошибка контекста C.

JSON evidence: [single-agent-tool-calls-validation.json](single-agent-tool-calls-validation.json).
Credentials и private fixture state в отчёт не включены.

Браузерная проверка выполнена в Safari через native CUA. Встроенный browser
host по-прежнему недоступен, но управление Safari работает. В основном чате
`53c17c79-cb1b-4d02-844d-6bc8b6233bfc` видны итоговая презентация и четыре
источника. Раскрытие источников и выбор «1. agent-a-pgate» открывает окно
цитирования с «Открыть выполнение». Нажатие ссылки переводит текущую страницу
на `/c/db1286cc-494b-439f-a28c-dd6fc2b7a2d0`: видны задание, FORECAST_A и
`forecast-A.csv`. Screenshot подтверждает полноэкранный дочерний чат.

Штатная сайд-панель сабагентов этим потоком не используется. Открывается
страница дочернего чата вместо основного, а не панель рядом с ним.
OpenRouter и переданный пользователем ключ не использовались и не сохранялись.
