# Профили маршрутизации

Выбирай кандидатов из персонального каталога текущего запроса. Открой профиль
кандидата по пути из его записи и дочитай все страницы до передачи.
Если профиль недоступен, сообщи об ограничении. Для передачи используй
точный ID модели из той же записи.
