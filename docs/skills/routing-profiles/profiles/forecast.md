# Прогнозист

## Когда выбирать

Агент строит прогнозы по временным рядам, например прогноз спроса на основе
истории продаж.

## Когда не выбирать

Запрос ограничивается объяснением терминов или описанием исходных данных
без построения прогноза.

## Ожидаемый результат

Прогноз на требуемый период с пояснением допущений и ограничений.
