# Spec Delta

## Purpose

Позволить параллельному агенту завершить создание интерактивной визуализации и показать её в собственном дочернем чате, даже когда пользователь остаётся в основном чате Router.

## ADDED Requirements

### Requirement: A supported visualizer belongs to the selected agent

Система SHALL поддерживать Inline Visualizer Tool и соответствующий Skill версии 2.2.3 в разрешённой Workspace Model работника на OWUI 0.12.3. Visualizer SHALL оставаться необязательным ресурсом выбранной модели. Неизменённая версия 2.1.1 SHALL NOT считаться подтверждённой совместимой конфигурацией.

#### Scenario: An allowed agent has the supported visualizer

- **WHEN** пользователю разрешён агент с согласованными Tool/Skill 2.2.3, доступными владельцу модели
- **THEN** параллельное задание использует эти ресурсы без отдельных grants пользователя на них
- **AND** другим работникам и Router они автоматически не добавляются

#### Scenario: The installation still uses the old tool

- **WHEN** установлен Inline Visualizer 2.1.1
- **THEN** инструкция совместимости указывает обновление согласованных Tool/Skill как необходимый шаг
- **AND** система не обновляет установленный пользователем плагин автоматически

### Requirement: Optional browser language detection cannot block the worker

Создание визуализации SHALL завершаться без обязательного подтверждения определения языка из браузера. В локальном контрольном сценарии поддерживаемый Tool SHALL завершаться не позднее восьми секунд от входа в Tool при отсутствии ответа браузера. Истечение ожидания SHALL позволять продолжить генерацию с языком по умолчанию, без повторного запуска задания.

#### Scenario: The browser remains on the main chat

- **WHEN** активная браузерная сессия открыта на основном чате, а работник вызывает Visualizer в ещё не открытом дочернем чате
- **AND** браузер не подтверждает запрос определения языка этого работника
- **THEN** Tool завершается в указанном контрольном пределе
- **AND** агент продолжает свой ответ и выдаёт содержимое визуализации

#### Scenario: The original browser tab disconnects

- **WHEN** браузерная сессия отключилась до определения языка
- **THEN** её отсутствие не удерживает Tool в ожидании до общего таймаута группы
- **AND** завершённую визуализацию можно открыть позже через дочерний чат

### Requirement: Visualization output is bound to its child execution

Embed и содержимое визуализации SHALL принадлежать дочернему чату и сообщению соответствующего задания. Запуск через `lite_parallel` SHALL NOT публиковать эту оболочку или поток HTML в основном чате. Ссылки и статусы основного чата SHALL сохранять прежнее поведение.

#### Scenario: Two different agents render concurrently

- **WHEN** A и B создают визуализации с разным содержимым для одного основного запроса
- **THEN** каждое дочернее выполнение содержит только свою визуализацию
- **AND** основной чат показывает прежние статусы, результаты и ссылки без добавленного embed работника

#### Scenario: One agent receives two visualization assignments

- **WHEN** два задания адресованы одной модели с Visualizer
- **THEN** они имеют разные дочерние исполнения и независимые визуализации
- **AND** завершение одного задания не заменяет содержимое другого

### Requirement: Opening a completed child displays the interactive visualization

При включённом пользователем разрешении iframe same-origin штатный интерфейс дочернего чата SHALL показывать сохранённую визуализацию поддерживаемого плагина. Для контрольного HTML/SVG без внешних библиотек SHALL отображаться ожидаемые элементы и работать локальное взаимодействие. Наличие только Tool result, сырых маркеров или пустой рамки SHALL NOT считаться подтверждением отрисовки.

#### Scenario: The user opens execution after the group completes

- **WHEN** пользователь нажимает «Открыть выполнение» после завершения задания
- **THEN** в дочернем чате видны ожидаемые SVG/HTML-элементы
- **AND** контрольная кнопка или переключатель изменяет состояние визуализации
- **AND** загрузка рамки завершается без повторного вызова Tool

#### Scenario: The child is opened while the worker is still generating

- **WHEN** пользователь открывает дочерний чат во время генерации содержимого после Tool
- **THEN** после завершения задания там доступна законченная интерактивная визуализация
- **AND** просмотр не запускает задание заново

### Requirement: Reopening a child preserves the saved visualization

После перезагрузки или повторного открытия дочернего чата завершённая визуализация SHALL восстанавливаться из сохранённого выполнения. Восстановление SHALL NOT требовать повторного исполнения Tool, нового запроса модели или присутствия исходной браузерной сессии.

#### Scenario: The child page is reloaded

- **WHEN** пользователь перезагружает страницу завершённого дочернего чата
- **THEN** ожидаемые элементы и локальная интерактивность визуализации снова доступны
- **AND** счётчики вызовов Tool и модели не увеличиваются

#### Scenario: The saved link is opened in another session of the same user

- **WHEN** владелец открывает сохранённую ссылку в другой своей браузерной сессии
- **THEN** визуализация отображается из того же дочернего выполнения
- **AND** её восстановление не зависит от подключения прежней сессии

### Requirement: Visualization inspection preserves existing execution boundaries

Просмотр визуализации SHALL сохранять штатную проверку доступа к дочернему чату, внутреннюю отметку и родительскую связь. Он SHALL NOT расширять набор Tools/Skills агента или выдавать пользователю новые grants на ресурсы. Система SHALL NOT автоматически включать пользовательское разрешение iframe same-origin.

#### Scenario: An unrelated user opens a copied execution link

- **WHEN** пользователь без штатного доступа открывает ссылку на чужое выполнение
- **THEN** история и визуализация ему не предоставляются

#### Scenario: The owner inspects a hidden agent

- **WHEN** владелец открывает визуализацию разрешённого агента, скрытого в селекторе
- **THEN** скрытость модели не препятствует просмотру
- **AND** дочерний чат остаётся внутренним и отсутствует в обычной истории

### Requirement: Visualizer support works with the existing deployment

Поддерживаемая связка SHALL работать с прежними двумя Functions без патча OWUI, новой БД и нового сервиса. Tool/Skill и необходимые статические зависимости SHALL подготавливаться заранее для закрытого контура. Для контрольной визуализации без внешних библиотек доступ к интернету во время исполнения SHALL NOT требоваться.

#### Scenario: A prepared installation renders without external services

- **WHEN** согласованные Tool/Skill заранее установлены и выполняется контрольная HTML/SVG-визуализация без CDN
- **THEN** задание завершается и визуализация отображается в дочернем чате без внешних сетевых запросов
- **AND** остальные агенты продолжают работать без установленного у них Visualizer
