# Spec Delta

## MODIFIED Requirements

### Requirement: Shared dialogue follows the selected agent

При обычном handoff агент SHALL получать текущий запрос, предшествующие пользовательские сообщения и видимые итоговые ответы всех исполнителей. Рабочий контекст SHALL сохранять относящиеся к запросу пользовательские файлы и видимые результаты, не копируя чужие системные инструкции. Параллельные работники SHALL получать самодостаточное поручение Router и выбранные вложения по parallel-agent-tasks вместо автоматической передачи родительской переписки.

#### Scenario: User refers to another agent answer

- **WHEN** ранее B ответил пользователю, а новое уточнение Router передал A обычным handoff
- **THEN** A получает текст уточнения и предшествующую видимую переписку, включая итоговый ответ B
- **AND** A не получает системный промпт или рабочие Skills B

#### Scenario: User supplied attachment survives handoff

- **WHEN** исходный запрос содержит поддерживаемый OWUI файл или изображение и Router выполняет обычный handoff
- **THEN** контекст выбранного агента сохраняет ссылку или штатное представление этого вложения
- **AND** передача не заменяет исходный запрос только пересказом Router

#### Scenario: Parallel worker receives an independent assignment

- **WHEN** Router запускает параллельное поручение, основанное на фактах из предыдущих сообщений
- **THEN** работник получает необходимые факты в самодостаточном поручении и выбранные доступные вложения
- **AND** исходная переписка не добавляется к его входу автоматически
- **AND** исходные сообщения сохраняются в основном чате для Router и последующего обычного handoff

### Requirement: Context limits do not silently change conversation meaning

Система SHALL NOT заменять историю пересказом при обычном handoff или для обхода лимита контекста, обрезать результаты без уведомления или повторять инструменты для восстановления данных. Самодостаточное поручение Router SHALL формироваться до запуска параллельного работника. При превышении доступного контекста SHALL возвращаться понятная ошибка. Сырые результаты другого агента SHALL NOT автоматически превращаться в собственную Tool-историю адресата.

#### Scenario: Context exceeds the provider limit

- **WHEN** подготовленная история не помещается в поддерживаемое окно модели
- **THEN** пользователь получает ошибку ограничения контекста
- **AND** система не скрывает усечение за успешным ответом

#### Scenario: Another agent needs a previously produced artifact

- **WHEN** A требуется результат B, представленный в общем ответе или доступном файле
- **THEN** A использует это общее представление с сохранением штатных прав
- **AND** отсутствующий в нём сырой Tool result B не подставляется автоматически как результат Tool A

#### Scenario: Parallel assignment exceeds the provider limit

- **WHEN** самодостаточное поручение с выбранными входными данными не помещается в контекст работника
- **THEN** система сообщает об ограничении контекста
- **AND** не запускает скрытый пересказ или повторное исполнение действий для обхода ошибки
