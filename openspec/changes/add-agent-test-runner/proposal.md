# Proposal

## Why

Репозиторий проверяет отдельные контракты Router, а оценка конкретной конфигурации агентов требует ручных запросов и сверки журналов. Нужен повторяемый прогон, который показывает покрытие подключённых моделей и позволяет различить ошибку выбора маршрута, сбой ресурса агента и проблему отрисовки Inline Visualizer.

## What Changes

- Добавить CLI для изолированного стенда Open WebUI 0.13.3. Он запускает размеченные сценарии через Router и, где это предусмотрено кейсом и разрешено пользователю, напрямую через выбранную Workspace Model.
- Сверять покрытие с настроенным `AGENTS`, а доступность адресата проверять в контексте указанного тестового пользователя.
- Поддержать управляемый провайдер для воспроизводимых проверок и явный прогон с реальными LLM, промптами и Skills тестируемой конфигурации.
- Перенести браузерные проверки Inline Visualizer 2.2.3 на Playwright и текущий протокол `delegate_task`.
- Собирать отчёт по всем выбранным кейсам с фактическим маршрутом, результатами отдельных проверок и причинами блокировки.

## Capabilities

### New Capabilities

- `agent-testing`: воспроизводимый запуск размеченных диалогов, проверка маршрутизации и ресурсов Workspace Models, браузерная проверка Visualizer и отчёт о покрытии.

## Impact

Изменение затрагивает инструменты и фикстуры в `tools/`, тесты, тестовый профиль OWUI и документацию по запуску. Playwright и браузер нужны в окружении тестов. Контракты исполнения Router и агентов остаются прежними.
