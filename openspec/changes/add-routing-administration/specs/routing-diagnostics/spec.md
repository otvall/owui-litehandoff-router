# Spec Delta

## Purpose

Помогает администраторам находить сбои в маршрутизации Open WebUI и воспроизводимо проверять выбранные группы агентов на изолированном стенде.

## ADDED Requirements

### Requirement: Inspect the current Router catalog

Административный агент SHALL показывать эффективный каталог указанного Router на момент запроса. Обзор SHALL использовать те же источник маршрутов и правила допуска, что рабочий Router, и выводить доступную причину исключения для запрошенной записи.

#### Scenario: Registered agent is missing from Router

- **WHEN** администратор запрашивает диагностику Router и известного зарегистрированного агента
- **THEN** результат показывает источник реестра, версию при её наличии и доступный статус записи
- **AND** результат различает ошибку записи или профиля, недоступность Skill, недоступность модели и отсутствие данных о причине

### Requirement: Inspect evidence for a routing turn

Диагностика SHALL принимать ссылку на чат и сообщение и показывать доступные сведения о кандидатах, чтении профиля, выбранном маршруте, попытке передачи и итоге исполнения. Новые ходы SHALL сохранять компактную трассу, достаточную для различения этих этапов.

#### Scenario: Correct routing is followed by an execution error

- **WHEN** трасса связывает успешную передачу ожидаемому агенту с последующим сбоем исполнения
- **THEN** диагностика указывает этап исполнения и подтверждающий статус
- **AND** предложение исправить routing-профиль требует отдельного свидетельства о проблеме в профиле

#### Scenario: Old turn lacks a trace

- **WHEN** доступный старый ход не содержит сведений о кандидатах или версии профиля
- **THEN** результат показывает подтверждённые по истории события и отмечает недостающие данные
- **AND** текущий каталог не используется как свидетельство состава исторического хода

### Requirement: Administrative diagnostics preserve chat access

Диагностические операции SHALL требовать административного доступа. Чтение хода SHALL применять штатные проверки доступа к чату и сообщению. Передача трассы SHALL ограничиваться сведениями, нужными для маршрутизации.

#### Scenario: Actor lacks access to the requested chat

- **WHEN** штатная проверка доступа к чату или сообщению не проходит
- **THEN** инструмент отклоняет просмотр и не возвращает трассу, содержимое чата или данные дочерних выполнений

### Requirement: Select diagnostic groups from the diagnostic Skill

Каталог групп SHALL храниться в `routing-diagnostics/references/test-groups.json`. Каждая группа SHALL содержать стабильный ID, описание и список точных Model ID. Оператор SHALL выбирать группу для группового ревью или прогона. Состав SHALL сверяться с выбранной версией `agents.json`.

#### Scenario: Operator selects a valid group

- **WHEN** оператор называет группу либо выбирает её из списка
- **THEN** агент показывает состав и версию проверенного каталога
- **AND** один Model ID может встречаться в разных группах
- **AND** публикация профиля и рабочий Router продолжают использовать `agents.json` без группы

#### Scenario: Group references a removed route

- **WHEN** один из Model ID отсутствует в реестре или не имеет пригодного профиля
- **THEN** агент сообщает конкретное несоответствие до запуска
- **AND** прогон не начинается с молча сокращённым составом

### Requirement: Run routing cases against a selected group on a test deployment

Групповой прогон SHALL использовать изолированный стенд и ограничивать каталог Router составом выбранной группы. Отчёт SHALL сохранять исходный состав, версию каталога, проверенные кейсы и ожидаемые и фактические решения.

#### Scenario: Operator runs a reported misroute

- **WHEN** оператор выбирает группу и запускает размеченный кейс с проблемным запросом
- **THEN** в тестовом Router участвуют ровно маршруты группы, подтверждённые в снимке
- **AND** результат различает выбор маршрута и исполнение агента и фиксирует недостающие свидетельства
- **AND** рабочий каталог Router остаётся прежним

#### Scenario: Runner cannot verify the source snapshot

- **WHEN** тестовый каталог не соответствует версии или разрешённому составу из выбранного профиля тестирования
- **THEN** тест-раннер останавливается до вызова агента и сообщает причину
