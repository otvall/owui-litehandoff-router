# Tasks

Все задачи относятся к единственной целевой версии **Open WebUI 0.12.5**. До изменения соответствующего кода каждая из трёх регрессий должна воспроизводить дефект; существующая зелёная suite не заменяет эти проверки. Контракты находятся в `specs/`, технические решения — в `design.md`.

## 1. P1 — MCP завершает работу вместе с запросом

- [x] 1.1 Добавить падающее воспроизведение Stop владельца обычного запроса при зависшем MCP-вызове в `tests/test_capabilities.py`: без ручного `session.close()` проверить автоматический disconnect, завершение session task и active/queued futures в пределах 5 секунд.
- [x] 1.2 Исправить единое идемпотентное закрытие в `capabilities.py`, включая отмену во время подключения и общий deadline нескольких сессий; unit cases из 1.1 и случаи repeated/concurrent close должны проходить без живых задач и бессрочных futures.
- [x] 1.3 Подключить этот lifecycle к полному запросу реальных Filter/Pipe, сохранив сессию между Tool-продолжениями; native integration должна автоматически закрывать сессии после success, provider/stream error и Stop, без ручного close до проверки результата.
- [x] 1.4 Дополнить native MCP transport и parallel cleanup cases: реальный SDK 2.x disconnect после Stop/deadline, два работника и два пользователя, гонка явного и автоматического закрытия; закрытие одного запроса не прерывает сессию другого и не повторяет вызовы.
- [x] 1.5 Уточнить lifecycle в `docs/setup.md` и `docs/compatibility.md`: граница полного запроса, бюджет локального закрытия, поддержка продолжений и отсутствие гарантии отката удалённой операции; сверить каждое утверждение с результатами 1.1–1.4.
