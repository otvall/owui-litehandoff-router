# Proposal

## Why

После обновления Open WebUI до v0.13.0 пользователь сообщает о неработающем Open Terminal. Текущий комплект рассчитан строго на 0.12.5 и отклоняет 0.13.0 ещё при создании адаптера; требуется перенести интеграцию и подтвердить реальное выполнение терминальных команд, а не только разрешить новую версию.

## What Changes

- Указать OWUI 0.13.0 как версию разработки в информационной metadata Functions; убрать runtime version guard и обязательную metadata версии. Native pin остаётся только для воспроизводимости проверок.
- Проверить используемые внутренние API v0.13.0 и адаптировать только несовместимые вызовы для моделей, Skills, Tools/MCP, фильтров, native continuations и дочерних чатов.
- Восстановить и доказать работу серверного Open Terminal: команда → файл → чтение/отображение → продолжение генерации при обычном, параллельном и финальном handoff.
- Сохранить привязки `meta.lite_handoff.terminal_id`, проверку прав владельца модели, личность исполнителя, действительную политику контекстов и отсутствие терминала у Router/агентов без привязки.
- Выпустить согласованную пару самостоятельных Filter/Pipe, обновить инструкции установки и записать новые результаты приёмки отдельно от исторических результатов 0.12.5.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `workspace-model-execution`: информационная отметка версии разработки 0.13.0 и автономная установка без ограничения runtime по номеру версии.
- `agent-terminal-access`: уточнить контракт терминального исполнения на 0.13.0, включая реальные файловые результаты и отсутствие зависимости от открытой браузерной панели.

## Impact

Затронуты `src/lite_handoff_router/owui_adapter.py`, подготовка capabilities/terminal scope при необходимости, `tools/build_functions.py`, оба файла `dist/`, `requirements-native.txt`, native test runner/environment, unit/native tests, terminal/product acceptance fixtures, README и руководства установки/приёмки. Штатный OWUI и Open Terminal не патчатся; production-данные не мигрируются этим проектом. Отдельные адаптеры прежних релизов, интерактивные пользовательские shell Tools и автоматическое подключение terminal Skills/AGENTS.md не входят в изменение. Активное `fix-parallel-worker-task-context` остаётся отдельным изменением, его работа не перезаписывается.
