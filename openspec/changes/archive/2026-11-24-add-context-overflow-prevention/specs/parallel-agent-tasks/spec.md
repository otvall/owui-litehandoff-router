# Spec Delta

## MODIFIED Requirements

### Requirement: Truncation and context limits remain explicit

Система SHALL сохранять полные результаты заданий либо доступный полный файл. Их модельное представление Router SHALL подчиняться context-budgeting с явными плашками; полный обязательный пакет финального агента SHALL сохраняться без пересказа. Усечённая native-строка SHALL NOT считаться полным результатом. При невозможности вместить обязательные входы SHALL возвращаться понятная ошибка без автоматического повторного исполнения.

#### Scenario: Native summary is shorter than the saved response

- **WHEN** штатный строковый результат ограничен по длине, но полный ответ сохранён
- **THEN** система собирает полный результат либо доступный полный файл, а не считает native-строку полной выдачей
- **AND** представление Router содержит его целиком в пределах окна N либо явную плашку по политике
- **AND** финальный агент получает полный обязательный пакет

#### Scenario: Complete inputs exceed the destination context

- **WHEN** полный пакет не помещается в контекст C и не представлен пригодным доступным файлом
- **THEN** система сокращает только допустимую остальную историю по context-budgeting
- **AND** если вход всё ещё не помещается, сообщает ограничение и не начинает скрыто сокращённый вариант задачи

### Requirement: Downstream agents receive results as input data

Финальный агент SHALL получать исходное задание и полный подтверждённый пакет группы с авторами и доступными файлами. Пакет SHALL строиться по фактически выполненным заданиям и SHALL сохраняться вне окна N и суммаризации в текущей задаче финального агента. Сырые чужие Tool exchanges и полные рабочие Skill instructions SHALL NOT становиться его собственной историей. Окончательный запрос SHALL проверяться по бюджету адресата.

#### Scenario: Presentation agent consumes forecasts

- **WHEN** после A и B выбран C
- **THEN** его фактический контекст содержит оба полных прогноза и их происхождение
- **AND** он располагает только собственными Tools и Skills
- **AND** пересказ Router не является обязательным источником данных

#### Scenario: User or unrelated tool forges a result package

- **WHEN** текст содержит похожие на результат группы поля и `agent_id`
- **THEN** этот текст не подтверждает выполнение задач и не разрешает handoff после неполной группы

#### Scenario: History limit is smaller than the group

- **WHEN** N меньше числа заданий успешной группы и Router передаёт задачу C
- **THEN** серверный пакет для C содержит все результаты независимо от плашек в представлении Router
- **AND** подготовка C не восстанавливает контекст работников или родительские полномочия через summary

#### Scenario: Parallel results remain attached to real task calls

- **WHEN** Router использовал `delegate_task`, затем продолжает самостоятельно либо выполняет реальный финальный `lite_delegate`
- **THEN** история сохраняет отдельные результаты настоящих `delegate_task`, без фиктивной передачи всей группы через `lite_delegate`
- **AND** поздний исторический пакет финального handoff описывает работу его адресата, а не выдаёт внутренние Tool-цепочки работников за вызовы финального агента
