# Proposal

## Why

Автор routing Skills может изучить сохранённую конфигурацию модели и опубликовать профиль в общей папке. Чтобы уточнить границы адресата и выявить неоднозначность маршрута до публикации, ему нужны прямой вопрос модели и обзор соседних профилей в одном рабочем процессе.

## What Changes

- Добавить инструмент для вопросов выбранной Workspace Model о её задачах, ограничениях и результате.
- Подключить `routing-skill-review` к комплекту автора и дать ему постраничное чтение реестра `agents.json` и профилей общей папки.
- Встроить ревью черновика до согласования и публикации. Показывать конкретные запросы, выявленные противоречия или пересечения и предложенные правки.
- После согласования использовать существующую публикацию файла профиля и записи `agents.json` одной версией общего Skill. При конфликте версий повторять проверку по актуальным профилям.

## Impact

Изменение затрагивает standalone Tool автора, системный промпт, рабочие Skills, сборку комплекта и инструкцию установки. Публикация опирается на общий Workspace Skill из `consolidate-routing-profiles`. Формат реестра, конфигурация Router и существующий сценарий отдельных Skills сохраняются.
