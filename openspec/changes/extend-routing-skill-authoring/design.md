# Design

## Context

Автор работает как обычная Workspace Model Open WebUI 0.13.3. Его standalone Tool читает writable-конфигурации и сохраняет профиль с `agents.json` через штатный update Skill. `inspect_shared_routing_profile` предназначен для редактируемой модели и не перечисляет соседей. Скилл `routing-skill-review` уже описывает смысловую проверку, распространяется отдельной сборкой и ссылается на устаревшее имя индекса `routing.json`.

## Goals / Non-Goals

**Goals**

- Дать автору доступ к консультации и ревью в обычном чате автора с native function calling.
- Связать проверенный снимок каталога с версией, которую проверяет при записи Open WebUI.

**Non-Goals**

- Выполнение рабочих инструментов адресата, проверочный прогон Router и автоматическое редактирование соседних профилей.
- Изменение формата реестра или разрешений моделей, Skills и Router.

## Decisions

### Вопрос целевой модели

Добавить метод `ask_agent(model_id, question)` в существующий standalone Tool. Загружать пользователя из серверного `__user__`, проверять write и штатное право запуска модели при каждом вызове. Передавать один вопрос через штатную генерацию OWUI с системным промптом адресата. Использовать изолированный запрос без chat ID, вложений и унаследованных метаданных, а также без цикла инструментов. Ограничить размер вопроса, ответа и время ожидания. Возвращать точный ID и текст либо статус недоступности. Отклонять самовызов и Pipe/Pipeline либо другие виды адресатов, для которых такой режим невозможно гарантировать.

Полный `delegate_task` даёт рабочий контекст и создаёт дочернее выполнение. Для консультации достаточно текстового ответа обычной модели. Ответ обрабатывается как сведения о специализации. При расхождении с прочитанными источниками автор показывает расхождение и запрашивает уточнение.

### Чтение общего Skill

Добавить постраничный список записей и чтение зарегистрированного профиля с аргументами `skill_id`, `model_id` для профиля и `expected_version_id` для продолжения. Первая страница списка возвращает версию, которую используют последующие страницы и чтение профилей. При несовпадении версии вернуть конфликт. Использовать штатную проверку read на общий Skill с каждым вызовом и существующий разбор `agents.json` и путей. Возвращать только маршрутизационные записи и их тексты. Индивидуальные права записи на модели по-прежнему проверяются при чтении их конфигурации и публикации. Список writable-моделей не подходит для ревью, поскольку состав зарегистрированных маршрутов может быть шире.

### Ревью и запись

Подключить существующий `routing-skill-review` к автору и обновить его инструкции под `agents.json`, новые readers и проверку неопубликованного профиля. До согласования показывать выводы ревью и оба полных списка примеров в чате. При обновлении сравнивать черновик с остальными зарегистрированными профилями. Смысловые решения остаются у автора и пользователя, а серверные Tools отвечают за доступ, чтение, рендер и запись. Ревью выполняется как часть инструкций автора.

После согласования передавать в существующий `save_shared_routing_profile` версию из ревью. Не подставлять новую версию из отдельного чтения перед записью. При конфликте заново прочитать каталог и повторить ревью, затем согласовать существенные правки. Сценарий отдельных Skills продолжает использовать прежние инструменты.

## Risks / Trade-offs

- Консультация может вернуть уверенный ответ о неподтверждённой возможности. Автор сверяет его с источниками и показывает существенный пробел.
- У большого каталога тексты могут не поместиться в контекст. Автор читает страницы, сравнивает группы профилей и указывает объём проверенного набора, если обзор остался неполным.

## Migration Plan

Вложить воспроизводимый `routing-skill-review.zip` в общий архив автора, используя тот же исходник, что и отдельная сборка ревью. Обновить установленный Tool, инструкции и рабочий Skill автора с сохранением существующих ID. Импортировать и прикрепить обновлённый Skill ревью. Для отката вернуть предыдущий комплект автора. Формат уже опубликованного общего Skill совместим с предыдущим комплектом.
