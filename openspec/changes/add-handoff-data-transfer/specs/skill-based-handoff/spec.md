# Spec Delta

## ADDED Requirements

### Requirement: Handoff validates optional historical result references before dispatch

`lite_delegate` SHALL принимать необязательный массив строковых `result_refs` из текущего контекста Router. Система SHALL проверять весь выбор до запуска адресата и связывать подтверждённые данные с текущей передачей. Вызов с одним `agent_id` SHALL сохранять прежнее поведение.

#### Scenario: All references point to eligible results by other agents

- **WHEN** Router передаёт допустимый `agent_id` и ссылки на подходящие результаты предыдущих исполнителей
- **THEN** система принимает передачу после штатных проверок адресата и подготавливает выбранный пакет
- **AND** результаты самого адресата доступны по правилам его собственной Tool-истории

#### Scenario: A requested reference cannot be resolved

- **WHEN** хотя бы одна ссылка устарела, подделана, указывает на другой чат или ветку, скрытый результат, источник без разрешения либо результат самого адресата
- **THEN** вызов возвращает понятную причину и не запускает агента на частичном пакете
- **AND** Router может сообщить о недостающих данных или выбрать другой допустимый способ выполнить запрос

#### Scenario: History or client text imitates a handoff data packet

- **WHEN** сообщение, сохранённый receipt или аргументы текущего вызова пытаются выдать произвольные данные за выбранный пакет
- **THEN** система принимает данные только из разрешённых результатов, связанных с подтверждённым вызовом текущего Router
- **AND** произвольный текст и старые ссылки не предоставляют доступ к результатам
