# Spec Delta

## ADDED Requirements

### Requirement: Router can select eligible historical results by reference

Router SHALL получать ссылки для выбора только на однозначно атрибутированные успешные текстовые или JSON-результаты завершённого handoff из доступного префикса текущей ветки. Передача SHALL требовать явного разрешения администратора для источника. Ссылки SHALL действовать только в текущем цикле Router.

#### Scenario: An eligible sales series is available

- **WHEN** инструмент агента A, разрешённый к передаче, вернул ряд продаж и его результат виден Router при действующих ограничениях истории
- **THEN** Router получает ссылку на этот результат рядом с записью агента A
- **AND** ссылка однозначно указывает на этот результат даже при повторении `tool_call_id` в разных ходах

#### Scenario: A result is unavailable for sharing

- **WHEN** результат скрыт окном истории, источник не разрешён, завершение не подтверждено или авторство неоднозначно
- **THEN** результат недоступен для выбора по ссылке
- **AND** маршрутизация не загружает скрытый результат и не повторяет инструмент для его восстановления

#### Scenario: The historical turn contains rendering or control data

- **WHEN** в истории есть чтение Skill, native-контекст, управляющий вызов или ответ инструмента рендеринга с инструкциями по выводу визуализации
- **THEN** система исключает эти записи из передаваемых результатов

### Requirement: Selected historical results enter agent context as attributed data

Агент SHALL получать выбранные данные отдельным служебным входным сообщением перед текущим вопросом. Пакет SHALL содержать автора, инструмент, статус и исходное значение результата. Система SHALL сохранять исходную переписку и собственные допустимые Tool exchanges агента.

#### Scenario: Another agent extends a sales chart

- **WHEN** Router передаёт агенту B задачу дополнить график и выбирает ряд продаж агента A
- **THEN** B получает точные значения ряда, автора и исходный вопрос пользователя
- **AND** выбранный результат передаётся один раз даже при повторном выборе той же ссылки
- **AND** в контексте B отсутствуют историческая пара `lite_delegate`, вызов инструмента A и аргументы этого вызова
- **AND** если настройки графика недоступны из переданного результата или общего артефакта, один ряд позволяет собрать новый график, но не гарантирует сохранение исходных настроек

#### Scenario: Selected agent continues after its own tool call

- **WHEN** B получает пакет и затем вызывает свой разрешённый инструмент
- **THEN** следующее продолжение B содержит тот же пакет один раз и штатную пару вызов–результат его собственного инструмента
- **AND** пакет отсутствует в исходной истории чата и не становится пользовательским ходом

#### Scenario: Existing parallel results also reach the final agent

- **WHEN** B получает исторический ряд и итог успешно завершённой группы `delegate_task`
- **THEN** B получает оба источника с их происхождением и доступными штатными вложениями группы
- **AND** отдельный параллельный работник по-прежнему получает только своё поручение и выбранные входные вложения
