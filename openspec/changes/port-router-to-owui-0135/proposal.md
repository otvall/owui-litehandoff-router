# Proposal

## Why

Open WebUI 0.13.5 убрал синхронный режим `subagents.delegate()` для обычного сохранённого чата. Текущий адаптер падает на изменившейся сигнатуре, а встроенное фоновое продолжение может начать новый ход родителя до завершения всех воркеров, тогда как Router должен передать полную группу итоговому агенту в исходном сообщении.

## What Changes

- Добавить поддержку штатного Open WebUI 0.13.5 для существующих Filter и Pipe. Сохранить 0.13.3 в матрице совместимости и сделать 0.13.5 основной версией разработки комплекта.
- Адаптировать запуск и остановку дочерних исполнений к API 0.13.5. Сохранить `delegate_task(agent_id, task, file_ids?)`, проверку всей группы и `lite_delegate` в том же родительском ответе.
- Подключить дочерние чаты роутера к штатному списку **Status → Threads** в 0.13.5, сохранив ссылки на конкретные выполнения и детальные статусы группы.
- Восстановить совместимость существующих сценариев с изменениями Machines, файлов, MCP, истории и передачи защищённого native-контекста.
- Проверять совместимость локально с управляемым провайдером, а выбор маршрута, порядок Tool calls и итоговый синтез отдельно проверить на GLM‑5.3‑Flash.

### Modified Capabilities

- `parallel-agent-tasks` — синхронная группа на штатном 0.13.5, с учётом административного доступа к сабагентам.
- `agent-task-inspection` — видимость, открытие и остановка дочерних задач через штатные Threads в 0.13.5.
- `workspace-model-execution` — автономный комплект для 0.13.5 с сохранением поддержки 0.13.3.

## Impact

Затрагивает OWUI-адаптер, запуск воркеров, нативные тесты, экспорт Functions и инструкции установки. Комплект использует штатную миграцию данных OWUI. Существующие требования к изоляции ресурсов, контексту и финальной передаче применяются на обеих версиях. Это изменение охватывает текущий Router и его опубликованные сценарии. Активные изменения по передаче данных handoff и отдельному тестовому раннеру ведутся отдельно.
