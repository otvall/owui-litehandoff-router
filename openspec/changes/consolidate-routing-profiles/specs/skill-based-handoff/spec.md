# Spec Delta

## MODIFIED Requirements

### Requirement: Routing is part of normal inference

Router SHALL принимать решение в обычном цикле ответа, используя переписку, свои базовые Tools и актуальные маршрутизационные профили. Система SHALL NOT запускать отдельный LLM-классификатор перед каждым сообщением.

#### Scenario: General question needs no specialist

- **WHEN** задачу можно решить средствами Router и подходящая передача не требуется
- **THEN** Router отвечает самостоятельно
- **AND** система не создаёт отдельный запрос к классификатору или агенту

#### Scenario: Router consults a routing skill

- **WHEN** описание профиля подходит к задаче и полные инструкции ещё не загружены
- **THEN** системный промпт требует успешно прочитать профиль в рамках обычной Tool-цепочки до передачи
- **AND** передача выполняется настоящим вызовом `lite_delegate` с точным `agent_id` из актуального манифеста

### Requirement: Mandatory routing skill reading instructions

Системный промпт Router SHALL требовать успешное чтение профиля адресата в текущем запросе перед `lite_delegate` и каждым назначением `delegate_task`. Промпт SHALL требовать полный профиль с ограничениями и примерами и запрещать передачу при ошибке чтения. Прочитанный целиком профиль SHALL оставаться пригодным для повторного использования в текущем запросе.

#### Scenario: Router relies on a catalog description or past reading

- **WHEN** отдельный routing Skill кандидата ещё не был успешно прочитан в текущем запросе
- **THEN** промпт требует вызвать `view_skill` и применить полный профиль до передачи
- **AND** совпадение с описанием каталога или прошлое чтение не отменяет это требование

#### Scenario: Reading fails

- **WHEN** routing Skill или файл профиля недоступен либо чтение завершилось ошибкой
- **THEN** промпт требует сообщить об ограничении и воздержаться от передачи этому агенту

#### Scenario: Router consults a profile in the shared skill

- **WHEN** запись кандидата содержит путь к файлу общего Skill
- **THEN** промпт требует вызвать `read_skill_file` с ID и путём из записи и дочитать страницы до конца, если они есть
- **AND** чтение общего `SKILL.md`, просмотр списка файлов, поиск или чтение профиля другого агента не заменяют эту загрузку
- **AND** перед передачей Router использует `agent_id` из той же записи
