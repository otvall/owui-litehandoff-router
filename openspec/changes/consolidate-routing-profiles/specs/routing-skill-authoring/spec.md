# Spec Delta

## MODIFIED Requirements

### Requirement: Saving and Router registration are distinct

Успешное сохранение отдельного Skill SHALL вернуть Skill ID, имя, версию, активность и пару Model ID → Skill ID. При сохранении профиля в общем Skill результат SHALL вернуть Skill ID, Model ID, путь и версию обновлённого Skill. Tool SHALL NOT изменять Valves, прежний `AGENTS`, permissions или модели. Результат SHALL обозначать проверку доступности через Router как отдельный шаг.

#### Scenario: New Skill is saved successfully

- **WHEN** штатный обработчик подтвердил создание отдельного Skill
- **THEN** помощник сообщает сохранённые ID и версию и сообщает запись для реестра
- **AND** отдельно указывает ручной шаг подключения, включая read-доступ владельца Router и сохранение остальных записей
- **AND** успешное сохранение не выдаётся за проверенную доступность через Router

#### Scenario: Shared profile is saved successfully

- **WHEN** профиль и его запись сохранены в одной версии общего Skill
- **THEN** помощник сообщает Skill ID, Model ID, путь и версию
- **AND** он поясняет, что Router использует запись со следующего запроса при подключённом `routing_skill_id` и действующих правах
- **AND** проверка позитивного, негативного и неоднозначного запросов остаётся отдельным шагом

## ADDED Requirements

### Requirement: Shared routing profile and registry entry publish together

Помощник SHALL сохранять отрендеренный профиль и запись агента в `agents.json` одной версионируемой операцией OWUI. Сохранение SHALL требовать права записи пользователя на модель адресата и общий Skill, а также актуальную версию Skill. Прочие профили, файлы, записи, владелец, права и активность SHALL сохраняться.

#### Scenario: Author adds or updates an agreed profile

- **WHEN** автор согласовал профиль, имеет оба права записи и передал версию после чтения общего Skill
- **THEN** запись точного Model ID указывает на файл из той же опубликованной версии с согласованным описанием
- **AND** остальные записи и файлы сохраняются

#### Scenario: Author has model write but no shared skill write

- **WHEN** автор может редактировать модель, но не общий Skill
- **THEN** операция отклоняется до изменения профиля или реестра

#### Scenario: Another author publishes first

- **WHEN** автор передаёт устаревшую версию либо пытается записать профиль по пути, занятому другим агентом
- **THEN** операция отклоняется без изменения файла или реестра
- **AND** перед новой попыткой помощник перечитывает актуальное состояние
