# Proposal

## Why

Добавление агента сейчас требует создать отдельный Workspace Skill и зарегистрировать его вручную в Python-фильтре. Общий Workspace Skill позволит администраторам маршрутизации редактировать реестр и профили в Open WebUI и публиковать их одной версией.

## What Changes

- Объединить маршрутизационные профили в один Workspace Skill с общим `SKILL.md`, реестром `agents.json` и отдельным `profiles/*.md` для каждого агента. В Router Preparation добавить настройку `routing_skill_id` для подключения папки.
- Строить персональный каталог и оба списка адресатов из одной версии реестра с учётом актуального доступа пользователя к моделям. Router читает подробный профиль по пути только для доступного кандидата.
- Ограничить доступ модели к общей папке, включая список файлов и поиск. Полный реестр читает серверная подготовка.
- Добавить в помощник подготовки профилей режим, который согласованно обновляет файл профиля и его запись в `agents.json` одной штатной операцией Open WebUI с проверкой версии.
- Сохранить переходный режим для действующих установок с `AGENTS`. При настройке `routing_skill_id` вся маршрутизация использует общий Skill. Подготовить инструкции перехода и возврата на прежний реестр.

### Modified Capabilities

- `user-agent-registry` — выбор источника реестра, проверка профилей из одной версии Skill и единый персональный каталог.
- `skill-based-handoff` — чтение точного файла профиля перед обычной и параллельной передачей.
- `conversation-context` — поле пути в каталоге и обработка текущих и прошлых загрузок профилей.
- `workspace-model-execution` — ограничения для чтения и поиска по общей папке и изоляция рабочих Skills.
- `routing-skill-authoring` — сохранение профиля и записи реестра одной версией общего Skill.

## Impact

Изменение затрагивает Router Preparation, построение реестра, манифест и readers Pipe, системные инструкции Router и помощника, а также сборку и инструкции установки. Используются штатные Workspace Skills, их файлы, права и версии. Идентификаторы моделей и сигнатуры обоих инструментов передачи сохраняются.
