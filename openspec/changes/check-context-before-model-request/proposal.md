# Proposal

## Why

Замер входа предыдущего вызова не включает свежие результаты инструментов. Полное окно модели также делится между входом и ответом, поэтому его нужно учитывать при проверке подготовленного запроса.

## What Changes

- Оценивать полный вход перед каждым рабочим запросом и после применения сводки.
- Использовать последний совместимый замер провайдера для раннего сжатия даже при заданном бюджете.
- Вычислять доступный вход из полного окна с учётом резерва под ответ и запаса безопасности.

## Capabilities

### Modified Capabilities

- context-budgeting — проверка подготовленного входа, раннее сжатие и расчёт бюджета по полному окну.

## Impact

Router, агенты основного чата, параллельные работники, настройки Router Preparation и обе сборки Open WebUI.
