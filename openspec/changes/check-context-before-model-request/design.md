# Design

## Context

Open WebUI передаёт результат инструмента в следующем вызове. Перед отправкой система оценивает готовое представление, включая этот результат и схему инструментов.

## Goals / Non-Goals

- Раннее сжатие по предыдущему замеру провайдера и проверка текущего входа.
- Сохранение обработки переполнения провайдера.

## Decisions

- Общее полное окно определяет жёсткий бюджет. Из окна вычитаются резерв под ответ и встроенный запас безопасности.
- Общий порог раннего сжатия задаётся долей полного окна. Сигналом служит предыдущий замер или оценка текущего запроса.
- Сохранённые абсолютные пороги, переопределения окна и старые ручные пределы не применяются.
- Для выбора границы считаются символы компактного JSON доступной непересказанной истории рабочего запроса до упаковки истории агента. В размер входят оставленные окном результаты инструментов. Сохранённый пакет параллельной группы не учитывается. Граница проходит по первому концу целого хода на целевой доле или после неё. Доля новых ходов по умолчанию составляет 60%.
- Размер материала для суммаризатора считается отдельно и выводится в статусе. Общий предел в 60 000 символов удалён. Правила подготовки выдержек из результатов инструментов и таймаут 45 секунд применяются к суммаризации.
- Router и обычный агент применяют совместимую сохранённую сводку до оценки своего запроса. Следующее сжатие передаёт модели предыдущую сводку и ещё не покрытые ходы. Ход, который был текущим при первом сжатии, может стать допустимым после следующего вопроса.
- Оценка выполняется локально. Если провайдер всё же сообщает о переполнении до начала вывода, сохраняется существующая попытка сжатия и повтор запроса к модели.

## Risks / Trade-offs

- Оценка зависит от шаблона модели и представления медиа у провайдера. Запас безопасности компенсирует часть расхождений.
- Свежий результат инструмента может занять весь доступный вход. В этом случае остаётся явная ошибка бюджета.
- Подготовленный материал может переполнить окно суммаризатора. Ответ суммаризатора с ошибкой или признаком обрыва отклоняется, а рабочий запрос проверяется по его бюджету.
