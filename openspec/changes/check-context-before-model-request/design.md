# Design

## Context

Open WebUI передаёт результат инструмента в следующем вызове. Перед отправкой система оценивает готовое представление, включая этот результат и схему инструментов.

## Goals / Non-Goals

- Раннее сжатие по предыдущему замеру провайдера и проверка текущего входа.
- Совместимость с сохранёнными пределами входа и обработкой переполнения провайдера.

## Decisions

- Предел входа остаётся значением с учтённым резервом. Полное окно задаётся отдельно. Доступный вход определяется более строгим из применимых пределов.
- Переопределение окна по ID Workspace Model имеет приоритет над общим окном. Прежние настройки остаются в сохранённой политике и исключаются из схемы формы.
- При отсутствии жёсткого бюджета оценка текущего входа может запустить сжатие по порогу получателя. При наличии бюджета превышение проверяется после каждого обновления сводки.
- Оценка выполняется локально. Если провайдер всё же сообщает о переполнении до начала вывода, сохраняется существующая попытка сжатия и повтор запроса к модели.

## Risks / Trade-offs

- Оценка зависит от шаблона модели и представления медиа у провайдера. Запас безопасности компенсирует часть расхождений.
- Свежий результат инструмента может занять весь доступный вход. В этом случае остаётся явная ошибка бюджета.
