# Spec Delta

## MODIFIED Requirements

### Requirement: Bound agents execute server terminal tools through the native loop

На Open WebUI 0.13.0 агент с допустимой привязкой SHALL выполнять серверные терминальные Tools и получать инструкции сервера при обычном handoff, параллельной работе и финальном handoff через штатный Tool loop. Продолжения SHALL сохранять его привязку без накопления инструкций. Управление интерактивной панелью пользователя и автоматическое подключение терминальных Skills/AGENTS.md SHALL NOT добавляться.

#### Scenario: Handoff executes a command and reads its result

- **WHEN** A получает handoff и вызывает доступную на T команду, затем читает созданный ею тестовый файл
- **THEN** оба вызова действительно исполняются на T
- **AND** последующая генерация A получает результаты и сохраняет собственные настройки модели

#### Scenario: Mixed parallel group leads to a final agent

- **WHEN** A с терминалом и B без терминала успешно выполняют параллельные задания, после чего выбран C с собственной привязкой
- **THEN** A выполняет терминальные Tools в дочернем чате, B работает только со своими ресурсами, а C использует свою привязку в основном чате
- **AND** дочернему агенту не требуется открытая терминальная панель браузера

#### Scenario: Terminal file result survives native continuation

- **WHEN** агент на 0.13.0 выполняет команду создания файла, читает его и вызывает доступный `display_file`
- **THEN** прочитанное содержимое совпадает с созданным файлом, а штатный файловый результат указывает на терминал агента
- **AND** следующая генерация получает результат без повторного исполнения завершённой команды

#### Scenario: Terminal execution needs no browser terminal pane

- **WHEN** привязанный агент выполняет задание в основном или дочернем чате без открытой интерактивной панели терминала
- **THEN** серверная команда исполняется и её результат доступен в сохранённом выполнении
- **AND** браузерный терминал пользователя и его shell Tools не используются как замена серверного подключения
